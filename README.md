# GPAK Girls — Girl Pride Africa Kenya

The official website of **Girl Pride Africa Kenya (GPAK)**, a registered NGO dedicated to ending teenage pregnancy and sexual abuse among teenage girls in Kenya. GPAK empowers teen mothers and pregnant teens through education, vocational training, mentorship, and support — helping them rebuild their lives with dignity and hope.

🌐 **Live site:** [www.gpakgirls.com](https://www.gpakgirls.com)

## About the Website

This site is GPAK's digital presence. It exists to:

- Raise awareness about the challenges facing teen mothers in Kenya
- Showcase our programs and the impact they have
- Share success stories from the girls we serve
- Connect volunteers, partners, and donors with ways to get involved

## Tech Stack

- [Next.js 14](https://nextjs.org/) (App Router) with React 18
- TypeScript
- [Tailwind CSS](https://tailwindcss.com/) — mobile-first, responsive design
- [Lucide](https://lucide.dev/) icons
- Deployed on [Vercel](https://vercel.com/)

## Getting Started

Requires Node.js 18+.

```bash
git clone https://github.com/gondamol/gpakgirls.git
cd gpakgirls
npm install --legacy-peer-deps
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

### Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm start` | Serve the production build |
| `npm run lint` | Run ESLint |
| `npm run type-check` | Run the TypeScript compiler checks |
